# Center Plus SaaS — Backend

Backend لتطبيق إدارة السناتر التعليمية. Multi-tenant SaaS.

---

## 🚀 المميزات

- **Multi-tenancy** — عزل كامل بين السناتر
- **Super Admin** — لوحة تحكم لكل السناتر
- **إدارة كاملة:** طلاب، مواد، مجموعات، حضور، كروت
- **الامتحانات:** MCQ + مقالي + **AI Grading** (Gemini)
- **الفيديوهات:** مع تتبع المشاهدات
- **المدفوعات:** شهرية + تقارير
- **التقارير:** إحصائيات شاملة

---

## 🛠️ التقنيات

| الطبقة | التقنية |
|--------|---------|
| Backend | Flask 3.1 (Blueprints) |
| Database | Supabase (PostgreSQL) |
| AI | Google Gemini |
| Auth | JWT + bcrypt |
